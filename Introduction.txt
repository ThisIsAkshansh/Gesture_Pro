FEATURED WORK

GESTUREMOUSE PRO  |  macOS, computer vision, assistive interaction
A hands-free input project that uses a camera and hand gestures to
control the cursor and perform common actions. The project includes
gesture-based clicking, dragging, scrolling, sensitivity controls, a
camera view, and native macOS input integration.

A voice-enabled companion for GestureMouse Pro, designed to make
computer control more conversational. It supports spoken status and
help, uses offline speech components, and keeps protected actions
behind confirmation rather than silently executing uncertain requests.
